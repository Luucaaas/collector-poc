# Services backend (Python / FastAPI)

| Service | Rôle |
| --- | --- |
| `catalog-service` | Catégories, boutiques, articles, contrôle automatique, historique des prix, publication des événements |
| `notification-service` | Centres d'intérêt, préférences, consommation des événements, notifications |
| `fraud-service` | Règles de détection d'anomalies, alertes pour l'admin |
